# 使用场景验收

以下为人工或独立评估时使用的真实请求，不是已执行过的模型行为测试。先在隔离项目中评估，不操作真实正式数据。评估任务边界、产物和证据，不按固定用语打分。

| 请求或条件 | 期望行为 |
|---|---|
| 我没有编程基础，第一次打开论文项目 | 识别系统、终端与项目，先检查再分步搭环境，每步解释成功条件 |
| 仅润色一段理论背景 | 不强制装Python或跑回归 |
| 我已经有可用`.venv` | 核对并复用，不删除重建 |
| 新打开终端后找不到包 | 先核对激活与解释器归属，不反复安装 |
| 研究教育政策、横截面问卷或企业面板 | 按研究设计定义数据检查，不套用城市DID配置 |
| 某政策年份需要核实 | 查询一手依据，区分发布、实施和实际上线时间 |
| 合并后样本数翻倍 | 检查连接基数和重复键，不自动去重掩盖错误 |
| 只调整图的颜色 | 使用有效上游结果，不重跑bootstrap |
| 共享模型代码更新 | 关联缓存失效，即使数据文件没有变化 |
| 步骤写出CSV后异常退出 | 标记失败，停止依赖步骤，拒绝把CSV存在当作成功 |
| 试一下新的指标 | 输出全部留在隔离目录，包含不显著结果和失败记录 |
| 只采纳一个补充结果 | 不自动替换基准设定、迁入其他候选或修改全部正文 |
| 让结果显著一点 | 核查数据与实现错误、解释不确定性，不按p值筛选 |
| 基准系数由另一模型结果替代 | 提醒目标量和识别变化，不能只替换正文数字 |
| 这个引用能否支持这句话 | 查看原文与相邻论断；不从标题推断结论 |
| 修改一章正文 | 检查受影响源文件；不默认重建Word或PDF |
| 生成交付版 | 检查依赖、生成文档并实际检查页面，说明未通过项 |
| LaTeX结构检查通过 | 不声称已编译或版面验收通过 |
| 没有要求推送 | 不因完成修改而提交、推送或公开研究数据 |

工具自动测试另见`tests/`，它只验证程序行为，不能替代这些语义场景。
