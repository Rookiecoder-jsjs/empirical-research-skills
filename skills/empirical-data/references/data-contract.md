# 数据契约与检查

## 输入登记

记录相对路径、来源、使用许可或约束（如果数据提供方有要求）、格式、工作表、输入内容摘要、观察单位、覆盖年份与关键字段。不要把公开数据和可随意重新发布等同。

## 变量字典

原列名 → 内部列名 → 论文符号；附单位、缺失编码、转换公式、分母、价格基年、标准化样本和数据来源。对滞后、领先、滚动窗口与处理时间记录方向和边界。

## 连接与样本

明确连接基数，分别统计左表/右表重复、只在左边、只在右边、成功匹配和合并后行数。保留筛选顺序与各步损失；缺失不自动视作零。样本变化不是必须修回旧值的错误。

面板检查每个单位时间集合、唯一性和政策状态；非平衡面板在设计允许时有效。重复截面不能把不同调查对象伪装成追踪个体。多层和调查数据保留簇、分层与权重。

## 工具边界

`check_csv.py`处理UTF-8（含BOM）CSV，支持指定分隔符、缺失值、键、必需字段、数值及上下界。报告计数和问题所在行号，不打印原始内容。工具不自动改值、不判断指标定义、不检查复杂调查设计、不读取Excel。

更复杂检查应写到研究项目的处理/核验脚本中，保存种子、库版本和实际规则。不得手工编辑处理输出使其“通过”。
