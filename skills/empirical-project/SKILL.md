# 项目组织

先读项目约定，列出现有目录及实际数据来源。不为套模板自动移动文件或创建空壳目录。

## 文件归属

默认结构和配置见[目录与配置](references/layout.md)。核心区分是来源：用户或数据提供方交付的输入作为基础档案，即使已含构造变量；本项目脚本生成的内容属于可再生产物。

- 基础输入在分析阶段只读，保留原始名称与内容；重复或可疑文件列出证据，不自行删除。
- 下载或新增入库按用户请求明确保存位置，避免覆盖已有输入。数据授权和公开范围不是目录归属自动赋予的。
- 数据处理、匹配、估计写成脚本；不手工修CSV来达成目标。
- 图表、模型和日志归属输出；论文源文件与Word/PDF等派生交付物区分。
- 探索输出在独立主题目录内，检查复制脚本和导入模块的路径副作用。
- 路径相对项目根目录，支持中文和空格。项目根从真实位置或参数确定，不绑定用户名、盘符或当前机器。

## 初始化新项目

自带`init_project.py`只用标准库，默认显示计划，只有`--create`才创建；目标必须不存在或为空，并拒绝覆盖。不把初始化当成迁移已有项目的工具。

```text
python <skill-folder>/scripts/init_project.py <new-project-path>
python <skill-folder>/scripts/init_project.py <new-project-path> --create
```

缺少研究问题、变量或模型时配置保留未指定状态，不捏造设定。模板中的目录只是默认值，已有项目按实际映射。

## 维护

在运行手册记录输入→步骤→产物，配置保存可变参数。结果数字由产物提取，避免在多份说明中手抄维护。只有项目规定了多份规则文档同步时才同步那些文件。

交付说明新建/修改的路径、保留的既有结构、配置待补项与检查情况。提交和公开文件只在用户明确要求时进行。
